# 桃花源记

可环绕探索的 Three.js 三维微缩小岛。桃林两岸沿溪水通往岩洞，山后水道穿过村落与田畦。

## 本地启动

使用 Node.js 20.19+ 或 22.12+，在本目录运行：

```sh
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://127.0.0.1:5173/`）。浏览器需要支持 WebGL 2。

- 拖动小岛来环绕观察，滚轮缩放。触屏使用单指拖动、双指缩放。
- 用「全岛」「桃林」「村落」前往对应视角，到达后可以继续环绕和缩放。
- 划过或轻点可见水面产生涟漪。「白天 / 黑夜」和「春季 / 冬季」可独立切换。

运行 `npm run build` 生成 `dist/`。运行 `npm run preview` 在本地预览生产构建。
